# DOCX

Route the task before touching the document:
1. Read [references/workflows.md](./references/workflows.md) for the task shape: analyze, create, edit, redline, or render visually.
2. For new documents, read [docx-js.md](./docx-js.md) before authoring.
3. For OOXML edits, comments, or tracked changes, read [ooxml.md](./ooxml.md) before modifying the archive.
4. Default to tracked changes for third-party, legal, academic, business, or government documents.
5. Work on a copy or unpacked workspace, not the user's only source file.
6. Verify both content and presentation before presenting results: text diff or markdown extraction plus a visual pass when layout matters.
7. If a dependency is missing, use an environment-appropriate install path and ask before mutating the host system broadly.
